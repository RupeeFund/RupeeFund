The Rupee Fund is a community initiative from FOSS United, run by volunteers. We support small, independent free and open source projects, maintainers and builders across India. The [FOSS United Foundation](https://fossunited.org) is the fiscal host.

> The fund does not take payments yet. To hear when it opens, join the list at [rupeefund.org](https://rupeefund.org/subscribe).

## Getting Started

This repository holds the source of rupeefund.org. To work on it, read the [documentation](docs/).
